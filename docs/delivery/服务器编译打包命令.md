## 6 收集现有内核二进制

```bash
# 回到服务器用户主目录。
cd /home/lzu

# 新建大包目录；已有同名目录时应先另存旧包。
mkdir lzu-ram-1.0

# 建立内核文件目录，-p 同时建立中间目录。
mkdir -p lzu-ram-1.0/sg2042-kernel61/boot

# 收集当前实际使用的已安装内核镜像。
cp /boot/vmlinuz-6.1.80-lzu-ram+ lzu-ram-1.0/sg2042-kernel61/boot/

# 收集同一次构建的符号映射表。
cp sg2042-kernel61/System.map lzu-ram-1.0/sg2042-kernel61/boot/System.map-6.1.80-lzu-ram+

# 收集同一次构建的内核配置记录。
cp sg2042-kernel61/.config lzu-ram-1.0/sg2042-kernel61/boot/config-6.1.80-lzu-ram+

# 保留内核许可证说明。
cp sg2042-kernel61/COPYING lzu-ram-1.0/sg2042-kernel61/

# 保留内核各许可证文本，-a 保留目录结构与属性。
cp -a sg2042-kernel61/LICENSES lzu-ram-1.0/sg2042-kernel61/

# 收集已安装模块，排除开发源码链接和可能存在的旧 phys_mem。
tar --exclude='6.1.80-lzu-ram+/build' \
    --exclude='6.1.80-lzu-ram+/source' \
    --exclude='*/phys_mem.ko*' \
    -czf /home/lzu/lzu-ram-1.0/sg2042-kernel61/内核模块.tar.gz \
    -C /lib/modules 6.1.80-lzu-ram+
```

`tar -czf` 创建 gzip 压缩包，`-C /lib/modules` 从该目录收集指定版本模块；三个 `--exclude` 排除源码开发链接和旧驱动。本次 phys_mem 单独收集。如果模块文件不可读，再用 sudo 执行该条 tar，并将生成文件 chmod 644。

不收集打包服务器的 initramfs，也不将整份 grub.cfg 用于覆盖甲方配置。甲方在本机生成 initramfs，从本机原正常条目复制新启动项；沿用本机已有固件和设备树启动方式。

## 8 收集离线系统运行依赖和安装手册

先将配套新版《安装与测试说明.md》传到服务器的 `/home/lzu/安装与测试说明.md`。

```bash
# 建立离线依赖目录。
mkdir -p /home/lzu/lzu-ram-1.0/运行依赖

# 下载系统运行库、模块工具、启动文件工具及它们的依赖。
dnf download --resolve --alldeps --destdir /home/lzu/lzu-ram-1.0/运行依赖 glibc kmod dracut

# 将甲方安装手册收入大包。
cp /home/lzu/安装与测试说明.md /home/lzu/lzu-ram-1.0/安装与测试说明.md

# 创建环境记录，写入发行版信息。
cat /etc/os-release > /home/lzu/lzu-ram-1.0/打包环境.txt

# 追加架构记录。
uname -m >> /home/lzu/lzu-ram-1.0/打包环境.txt

# 追加运行内核版本。
uname -r >> /home/lzu/lzu-ram-1.0/打包环境.txt

# 追加板卡型号。
cat /proc/device-tree/model >> /home/lzu/lzu-ram-1.0/打包环境.txt

# 补充板卡型号后的换行。
printf '\n' >> /home/lzu/lzu-ram-1.0/打包环境.txt

# 记录系统 glibc 版本。
getconf GNU_LIBC_VERSION >> /home/lzu/lzu-ram-1.0/打包环境.txt

# 记录编译时使用的 Python 版本；应用运行时使用随包运行库。
/home/lzu/Failure_disturbance_suppression/.venv-build/bin/python --version >> /home/lzu/lzu-ram-1.0/打包环境.txt

# 记录 Nuitka 版本和编译环境信息。
/home/lzu/Failure_disturbance_suppression/.venv-build/bin/python -m nuitka --version >> /home/lzu/lzu-ram-1.0/打包环境.txt

# 记录交付驱动的完整内核标识。
modinfo -F vermagic /home/lzu/lzu-ram-1.0/Failure_disturbance_suppression-binary-riscv64/modules/phys_mem.ko \
    >> /home/lzu/lzu-ram-1.0/打包环境.txt
```

`--resolve` 下载依赖，`--alldeps` 包括本机已安装依赖，`--destdir` 指定下载目录。[DNF 下载插件说明](https://dnf-plugins-core.readthedocs.io/en/latest/download.html)。只下载发行版二进制 RPM，不下载源码 RPM；这些系统运行包可能带有自身的解释型运行文件，不含本工程源码。
